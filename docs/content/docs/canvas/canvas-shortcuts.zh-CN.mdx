# 画布快捷键

本文档记录画布里常用的鼠标和键盘操作。

## 视图

- 左下工具栏可在「选择」与「移动」之间切换，当前模式由图标显示。
- 选择模式下拖动空白处：框选多个节点。
- 移动模式下拖动空白处或节点：平移画布。
- 按住 `Control` 或空格：临时反转当前工具（选择 ↔ 移动），松开恢复，不改变工具栏状态。
- 鼠标中键拖动：平移画布。
- 鼠标滚轮：缩放画布。
- 缩放滑杆：精确调整缩放。
- 重置视图按钮：回到默认缩放和居中位置。

## 选择

- `Shift`、`Ctrl` 或 `Cmd` + 点击节点：追加或取消选择节点。
- `Ctrl / Cmd` + `A`：全选画布节点。
- `Esc`：取消选择，并关闭当前浮层。

## 编辑

- `Ctrl / Cmd` + `C`：复制选中节点。
- `Ctrl / Cmd` + `V`：粘贴节点。
- `Ctrl / Cmd` + `G`：将选中节点打组。
- `Ctrl / Cmd` + `Shift` + `G`：解散选中的组。
- `Delete / Backspace`：删除选中的节点或连线。
- `Ctrl / Cmd` + `Z`：撤销。
- `Ctrl / Cmd` + `Shift` + `Z`：重做。
- `Ctrl / Cmd` + `Y`：重做。

## 图片、视频和素材

- 拖入图片或视频文件：上传到画布并生成对应节点。
- 导入图片按钮：从本地选择图片。
- 我的素材：选择素材后插入画布。

## 撤销和重做范围

撤销和重做会记录画布节点、连线、视口、背景模式和助手会话变化。画布项目名称、账号状态、全局 AI 配置和“我的素材”保存操作不属于当前画布历史。
