# Canvas Shortcuts

## View

- Switch between **Select** and **Pan** in the bottom-left toolbar; the icon shows the active mode.
- In Select mode, drag empty canvas space to box-select nodes.
- In Pan mode, drag empty space or a node to move the canvas.
- Hold `Control` or `Space` to temporarily invert the tool (Select ↔ Pan); release to restore. The toolbar state does not change.
- Middle-mouse drag always pans.
- Use the mouse wheel or zoom slider to zoom.
- Use Reset View to restore the default zoom and centered position.

## Selection

- `Shift`, `Ctrl` or `Cmd` + click: add or remove a node from the selection.
- `Ctrl / Cmd` + `A`: select all nodes.
- `Esc`: clear the selection and close the active overlay.

## Editing

- `Ctrl / Cmd` + `C`: copy selected nodes.
- `Ctrl / Cmd` + `V`: paste nodes.
- `Ctrl / Cmd` + `G`: group selected nodes.
- `Ctrl / Cmd` + `Shift` + `G`: ungroup the selection.
- `Delete / Backspace`: delete selected nodes or edges.
- `Ctrl / Cmd` + `Z`: undo.
- `Ctrl / Cmd` + `Shift` + `Z`, or `Ctrl / Cmd` + `Y`: redo.

Drag image or video files onto the canvas to upload them, or insert saved items from My Assets. Undo and redo cover nodes, edges, the viewport, background mode, and assistant sessions; they do not cover the project name, account state, global AI settings, or the My Assets library.
