# Third-party Prompt Sources

No third-party prompt source is bundled any more. A fresh configuration starts with an empty source list: add standard JSON URLs on the **Prompt sources** settings page yourself. Built-in sources found in an existing server configuration are removed, while custom sources and their schedule are preserved.

## Fetch rules

- The server proxies every fetch (`/api/prompt-source/:id`); the browser never contacts external hosts directly.
- Only public HTTPS addresses are accepted; private hosts, internal networks, and redirects are rejected.
- The response root must be an array, and each item needs a non-empty `title` and `prompt`, otherwise that entry is skipped. A non-array root fails the whole refresh.
- A failed refresh keeps the last successful cache and reports source status with the last success time.

## Item fields

| Field | Meaning |
| --- | --- |
| `title` | Required prompt title |
| `prompt` | Required prompt body |
| `description` | Description text |
| `coverUrl` | Cover image; falls back to the first reference image |
| `referenceImageUrls` | Reference or result images; relative paths are allowed |
| `preview` | Preview content |
| `tags` | Tag list used for filtering |
| `author` / `sourceUrl` | Author and upstream link |
| `imageMode` / `imageModel` / `imageSize` / `imageCount` | Optional generation hints |
| `createdAt` / `updatedAt` | ISO timestamps |
