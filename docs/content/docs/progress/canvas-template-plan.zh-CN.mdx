# 画布模板规划

## 第一版：已实现，待用户验收

入口是画布菜单中的「保存为模板」、画布库的「模板库」以及新建弹窗的「从模板创建」。支持整张画布快照、名称、描述、自动缩略图、放大预览、搜索、编辑信息和删除。

- 模板按当前工作区保存在服务器的 `canvas-templates` 数据域，浏览器只持有运行时列表；不会把模板业务列表写入 localStorage 或新增本地权威副本。
- 保存的是节点、分组、连线、提示词、模型参数、背景和视口，不是源画布引用。不保存项目会话、服务端配置或任务 ID，运行状态会清理；创建模板画布不会触发生成。
- 源画布到模板、模板到新画布分别复制图结构和素材，以新标识持久化。模板封面也是服务器媒体；重复引用只在同一份副本内部去重，不在三者之间共用可改写的媒体标识。
- 先保存素材和封面，再提交模板元数据。模板保存、编辑和删除等待服务器确认才更新列表；模板新画布等待服务器确认才加入画布列表并进入编辑器。修订冲突拒绝覆盖，并沿用全局刷新处理。
- 封面是整张画布的静态结构概览，绘制连线、节点标题、文字摘要及图片；音视频不自动播放，插件不执行。插件独立存储和内容中嵌入的外部站点依赖不属于快照。
- 第一版不包含选区模板、插入当前画布、输入槽位、内容覆盖更新、分享、模板包导入导出或 WebDAV 模板快照。当前访问按真实会话及成员角色校验；旧版无成员工作区拒绝访问，需管理员明确绑定，不自动认领。

验收步骤和桌面、移动端及单元测试的自动化结果统一记录在[待测试](/zh-CN/docs/progress/pending-test)。已完成专项回归不代表全部人工验收通过；没有运行语法检查或构建。

## 二版目标

让模板从「整张画布的起点」扩展为可组合的小模块，同时保持保存语义清楚、不自动生成、不隐式同步。

优先级一、二，以及优先级三中的只读预览、服务端复制、成员校验、事务引用清单与仅报告的 GC dry-run 已实现，进入待测试。实际删除、模板包和分享仍是后续事项，不把前置条件未完成的规划标为已交付。

## 优先级一：选区模板与插入（已实现，待验收）

### 保存选区为模板

- 复用第一版的命名、描述、预览及服务器保存流程，不另建一套管理入口。
- 保存选中分组时一并纳入其成员，保留相对布局；只保存选区内部连线。
- 检查来自选区外的连线和参考素材，提示缺失的输入，让用户明确选择纳入依赖或保留为待填写输入；不能静默删除依赖后宣称模板完整。
- 上游依赖包含连线、提示词中的节点引用及能定位到原节点的媒体引用；没有对应节点的独立引用素材仍复制到服务器。外部文本、图片可转换为必填输入，配置、分组和插件依赖必须纳入。

### 插入当前画布

- 模板操作拆为「新建画布」和「插入当前画布」，不要覆盖当前画布。
- 插入到当前视口附近并整体选中，节点、分组、连线、结果和素材使用独立标识，便于整体移动。
- 插入为一次历史操作，撤销一次移除整个插入模块；撤销与重做仍保护媒体引用。

验收：同一模板可在一个画布中插入多次；重复节点和连线不冲突，现有内容及视口不被清空，撤销不误删其他模块素材。

## 优先级二：可填写输入与可控更新（已实现，待验收）

### 待替换输入

- 先支持把文本或图片节点标记为待填写输入，显示名称与说明，不直接引入复杂模板表达式。
- 使用模板时提供简短输入步骤，创建后仍能定位和修改相应节点；缺少必填输入时提示补全，不自动运行。
- 增加「保留生成示例」选择；取消后仅清空末端生成结果，保留连线输入、上传素材和显式引用，不能把它误写成无条件清空全部内容的结构模式。

### 更新模板内容

- 从画布菜单显式选择「更新已有模板」或「另存为新模板」；覆盖前预览更新范围并确认。
- 模板只保留用户确认后的内容，不自动跟随源画布，不修改已经创建的画布。第一步不做完整历史版本系统。
- 使用前检查模型和插件依赖，明确展示缺失项；模型不可用时让用户选择替代，不静默改用其他模型。

验收：模板改版不影响已有画布；取消覆盖保留原模板；缺失依赖能定位并处理，输入槽位不泄漏其他工作区数据。

## 优先级三：预览、传输与生命周期

- 已实现：可缩放、滚动查看的只读结构预览，点击或键盘选择节点查看类型、提示词、输入及模型详情；只绘制数据，不挂载节点或插件执行器，不触发生成或音视频播放。
- 已实现：已持久化素材通过受当前工作区读取及写入权限约束的服务端对象复制，新副本使用独立媒体标识；URL、Blob 或新上传输入仍需先上传。未引入可改写媒体共享或跨工作区复制。
- 已实现、待验收：工作区成员校验、跨画布/模板内容及封面/资产/生成记录的事务引用清单、version 1 独立 Agent 附件清单、持久化上传 intent、精确前缀对象对账与 GC dry-run；无索引对象仅作诊断，不接纳、不删除。崩溃遗留租约处置、对象代际及删除前 claim 仍按[媒体生命周期规划](/zh-CN/docs/progress/canvas-media-lifecycle-plan)推进。
- 明确模板包格式及素材清单后再做导入导出与 WebDAV 手动快照，错误导入不得部分提交；不扩展为双向自动同步。
- 工作区分享需要先厘清账户归属、成员权限和素材读取授权，再讨论只读分享或跨工作区复制，不直接上模板市场。

涉及新增超时、重试、大小限制和并发边界时，实施前先说明适用环节、默认值及失败处理，取得用户确认，不在二版开发时静默增加经验值。

## 建议落地顺序

第一版及二版已实现部分均保留在待测试清单，用户确认后再更新正式功能说明。当前停留在跨数据域引用核对、Agent 附件持久化、上传意图、对象对账和 GC dry-run，不执行删除。后续补崩溃遗留租约处置、对象代际与删除前隔离设计；模板包、分享与跨工作区复制仍须另行授权和安排。
