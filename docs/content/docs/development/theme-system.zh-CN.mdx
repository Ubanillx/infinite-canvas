# 主题配色规范

应用使用语义化全局变量和独立的画布主题。白天模式采用白玉方向：接近白色的背景、白色表面、极淡的暖灰边界、墨色文字和克制的阴影，不使用玉绿色作为品牌强调色。

## 白天模式变量

- `background`：`#fafaf8`，页面和应用背景。
- `surface`：`#ffffff`，卡片、弹层和浮起面板。
- `soft`：`#f4f4f0`，选中态和次级表面。
- `hover`：`#efefeb`，悬停反馈。
- `border`：`#e9e9e4`，弱边界。
- `text`：`#292b28`，主要文字。
- `mutedText`：`#676963`，次要文字。
- `primary`：`#30332f`，主要按钮和当前状态标记。

共用页面优先使用 `bg-background`、`bg-card`、`bg-muted`、`text-foreground`、`text-muted-foreground` 和 `border-border`。轻微层次使用 `--shadow-surface` 与 `--shadow-surface-hover`。不要在页面内新增绿色、stone 或纯黑白替代色。

## 画布模式

`web/src/lib/canvas-theme.ts` 将同一套中性色映射到画布网格、节点、面板和工具栏。需要绘图内联颜色时使用画布主题对象；普通页面控件使用全局语义变量。

深色模式保留现有暖炭黑方向，与白天模式相互独立。
