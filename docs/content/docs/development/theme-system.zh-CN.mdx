# 界面设计规范

应用使用语义化全局变量和独立的画布主题。浅色模式以接近白色的表面、暖灰边界和墨色文字为主；深色模式独立适配。不把效果图中的配色或示例数据直接搬进产品。

## 白天模式变量

- `background`：`#fafafa`，页面和应用背景；侧栏为 `#fbfbfb`。
- `surface`：`#fefefe`，卡片、弹层和面板。
- `soft`：`#f4f4f0`，选中态和次级表面。
- `hover`：`#efefeb`，悬停反馈。
- `border`：`#e9e9e4`，弱边界。
- `text`：`#292b28`，主要文字。
- `mutedText`：`#676963`，次要文字。
- `primary`：`#30332f`，主要按钮和当前状态标记。

共用页面优先使用 `bg-background`、`bg-card`、`bg-muted`、`text-foreground`、`text-muted-foreground` 和 `border-border`。颜色以 `web/src/lib/light-palette.ts` 和主题变量为准，不在单页硬编码另一套配色。

## 页面布局

- 画布库、提示词库、资产库使用一致的目录式节奏：左侧标题和简短说明，右侧主要操作，其下排列搜索、筛选和内容。列表与工作台利用可用宽度；阅读型表单和弹窗可按内容限制宽度。
- 内容按文件夹、项目或类型分组；空状态说明下一步，不填充假卡片。窄屏时工具栏自然换行，不能遮挡操作或产生横向溢出。
- 生图和视频工作台优先把空间留给参考素材、结果和提示词。设置与记录使用按需打开的侧栏；侧栏打开时主内容让位，配置项直接可见，避免二级展开。

## 组件与反馈

- 用细边框和轻微底色区分卡片、输入框及选中态。避免大面积投影、点阵装饰、高对比度描边和点击时外扩阴影；需要浮层层级时允许小范围轻阴影。
- antd 输入类控件（`Input`、`Input.TextArea`、`InputNumber`、`Select`）在默认、悬停和聚焦时只用微弱底色差与细边框区分：聚焦不出现 2px 外扩光环，深色模式也不用近白描边。相关颜色统一在 `web/src/lib/app-theme.ts` 的组件 Token 中配置，业务组件不逐个覆盖。
- 普通表单（如提示词编辑器）的输入框直接用上述全局三态，不写行内边框或阴影覆盖。生图、视频工作台的提示词框需要整块浅底色，复用 `app-prompt-input` 全局类；它只叠加底色递进，边框和聚焦仍由全局 Token 决定。
- 全站搜索框采用轻微底色区分默认、悬停和聚焦状态，不使用明显边框或阴影；聚焦状态仍须可辨识。
- 主要操作清楚但不过大，次要操作适度收敛。相关操作就近分组，避免所有功能平铺；点击区域应易于操作，纯图标按钮提供名称。
- 全站按钮点击只作轻微明度变化，不用外扩波纹或按下阴影；危险操作保留语义色，键盘焦点保持可辨识。
- 输入框保持足够空间；提示词可直接拖动边缘调整高度，无需额外拖动占位。参数摘要用次要文字，与生成按钮同一操作行；键盘焦点仍需有可辨识反馈。
- 素材缩略图保持比例；资产选择器和资源卡片中，点击图片先预览，插入、删除等操作使用独立按钮。同类弹窗尺寸协调、适应视口，长列表内部滚动。

以上规则适用于普通资源页和创作工作台；画布编辑区及品牌首页可按各自任务使用专属布局，不强制套用目录页结构。

## 画布模式

`web/src/lib/canvas-theme.ts` 将同一套中性色映射到画布网格、节点、面板和工具栏。需要绘图内联颜色时使用画布主题对象；普通页面控件使用全局语义变量。

深色模式保留现有暖炭黑方向，与白天模式相互独立。
